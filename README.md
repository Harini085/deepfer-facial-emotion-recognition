# 😊 DeepFER: Facial Emotion Recognition Using Deep Learning

DeepFER is a deep learning project that classifies human facial expressions into seven emotion categories using the FER2013 dataset. The project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, CNN model development, training, evaluation, and prediction.

---

## Project Overview

Facial Emotion Recognition (FER) is a computer vision task that enables machines to identify human emotions from facial expressions. It has applications in:

- Human-Computer Interaction
- Healthcare
- Mental Health Monitoring
- Driver Monitoring Systems
- Smart Surveillance
- Online Education
- Customer Experience Analysis

---

## Dataset

**Dataset:** FER2013

The dataset contains grayscale facial images of size **48 × 48 pixels** categorized into seven emotions.

### Emotion Classes

- Angry
- Disgust
- Fear
- Happy
- Sad
- Surprise
- Neutral
